# Content (sync from Obsidian)

This folder is intended to be synced from your Obsidian Vault (e.g. `Website/`).

Recommended structure:

- `content/blog/` blog posts (`type: post`)
- `content/grandpa/<section>/` grandpa's articles by section (`type: grandpa`)
- `content/pages/` standalone pages (`type: page`)
- `content/projects/` projects/works (`type: project`)
